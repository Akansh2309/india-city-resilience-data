## Overview
As India rapidly urbanizes, the intersection of extreme climate events and urban infrastructure resilience has become critical. This repository contains the data engineering pipeline used to build the **India Smart City Resilience Dataset**, an 8.7+ million row hourly time-series dataset tracking meteorological metrics across 50 major Indian cities over 20 years.

🔗 **[View and Download the full Dataset on Kaggle](https://www.kaggle.com/datasets/akanshshaw/india-smart-city-resilience-dataset-2004-2024)**

## The Pipeline
This dataset contains **0% synthetic data**. It was generated by extracting data directly from NASA's MERRA-2 and CERES satellite assimilation models. 

To bypass strict API request limits, the custom ETL pipeline (`fetch_nasa_data.py`) was engineered to:
1. Geocode 50 Indian cities to 4-decimal precision coordinates via OpenStreetMap.
2. Iteratively chunk 20 years of data into 1-year API payloads.
3. Handle missing NASA values (`-999.0`) by converting them to standard Nulls.
4. Concurrently process and append 8.7 million rows into a memory-safe `568MB` CSV.

## Running the Extractor Locally
To run the extraction pipeline yourself:
```bash
pip install -r requirements.txt
python data_collection/fetch_nasa_data.py
```
*Note: The generated CSV is intentionally git-ignored due to GitHub's file size limits. Download the final CSV from Kaggle.*

## Automated Updates
This repository utilizes **GitHub Actions** (`.github/workflows/update_data.yml`). On the first of every month, a cloud runner automatically spins up an Ubuntu environment, executes the Python extraction script to pull the latest 30 days of climate data, and verifies the pipeline's integrity.
